# Каталог распродаж

Статический каталог товаров из публичного Telegram-канала t.me/rasprodonetsk: поиск, категории, фильтр по цене, акции, подешевевшее, без Б/У.

- `scrape.py` собирает посты из публичного превью `t.me/s/<канал>` в `data/posts.jsonl` (`--new` дозабирает свежие).
- `build.py [дней]` разбирает цену и название, склеивает повторные посты, определяет категорию, скачивает и сжимает фото, пишет `site/data.js`.
- `site/index.html` сама витрина, без сборки и зависимостей.
- `update.sh` обновляет всё одной командой.

Локально: `cd site && python3 -m http.server 8080`.

Данные (`data/`, фото, `site/data.js`) в репозиторий не входят: это материалы канала, они собираются локально и не публикуются.
